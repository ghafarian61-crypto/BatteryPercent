# Battery Percent

ویجت درصد شارژ + صفحهٔ شارژ تمام‌صفحه برای گوشی‌های AMOLED (A34 / M62).

## رفتار
- وقتی شارژر وصل شود (یا موقع شارژ صفحه روشن شود) صفحهٔ سیاه با روشنایی ۱٪ باز می‌شود.
- از پایین پر می‌شود: قرمز ۱–۳۰، نارنجی ۳۱–۵۰، زرد ۵۱–۷۰، سبز ۷۱–۱۰۰. عدد آبی (بدون %) پایین و وسط.
- در ۱۰۰٪ یا با جدا کردن شارژر، خودش را کامل می‌بندد و در برنامه‌های اخیر دیده نمی‌شود.
- لمس صفحه آن را می‌بندد و تا وصل کردن دوبارهٔ شارژر باز نمی‌شود.
- لمس ویجت: درصد فعلی را ۱ ثانیه تمام‌صفحه نشان می‌دهد و بسته می‌شود.

## راه‌اندازی روی گوشی
1. APK را نصب و برنامه را یک بار باز کنید. هر بار که باز می‌کنید یک مجوز می‌خواهد:
   «Display over other apps» ← اعلان‌ها ← معافیت از بهینه‌سازی باتری. تا پیام «running» را ببینید.
2. ویجت را روی صفحهٔ اصلی بگذارید.
3. اگر قبلاً نسخهٔ قدیمی نصب بود و نصب خطا داد، اول آن را پاک کنید (امضای debug فرق دارد).

## ساخت
- GitHub: پوشه را push کنید. در تب Actions ← Build APK، فایل `BatteryPercent-debug` را دانلود کنید.
- یا Android Studio: پوشه را باز کنید و Run بزنید.

تغییر رنگ عدد: `ChargeView.NUMBER_COLOR`. روشنایی: `DIM_BRIGHTNESS` در `ChargeActivity`.
